# database/seed/

بيانات أولية: المزوّدون، الامتدادات، شرائح التسعير المعتمدة، خطط DNS،
والإعدادات العامة.

## قواعد ملتزَمة بالحرف
1. **ممنوع** أي سعر تكلفة من مزوّد حقيقي — التكاليف بتتجيب من الـAPI وقت
   التشغيل (ومفيش صف واحد في `provider_costs`).
2. **ممنوع** أي سعر صرف مخترع — جدول `fx_rates` **فاضي قصدًا**. لحد ما يدخل
   سعر معتمد (`is_approved = true`)، أسعار EGP تفضل موقوفة. ده سلوك صح،
   مش عطل.
3. **ممنوع** أي سرّ — عمود `credentials_ref` مرجع بس.
4. كل الإدخالات idempotent (`on conflict do update/do nothing`).

## المحتوى
- **`providers`**: `openprovider` (المعتمد، مقفول) · `cloudflare` (بديل بقيود) · `mock` (محلي).
- **`domain_tlds`**: com · net · org · io · app · dev · store · eg — وعمود `rdap_url` فاضي قصدًا (بيتحدّد من IANA Bootstrap وقت التشغيل).
- **`pricing_rules`**: الشرائح الأربعة المعتمدة بوحدة ميكرو-دولار.
- **`dns_plans`**: أساسية مجانية نشطة، ومتقدّمة **مقفولة** بلا سعر.
- **`system_settings`**: مفاتيح الميزات كلها `false`، ومدد الـCache، ومعدّل الاستعلام.

## ⚠️ الحالة
**مكتوب للمراجعة — لم يُنفَّذ** على أي قاعدة بيانات حقيقية. التنفيذ محتاج
موافقة صاحب المشروع، وتطبّق بعد الـmigrations.
