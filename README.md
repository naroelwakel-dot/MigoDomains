# Migo Domains

منصة بيع وإدارة الدومينات الخاصة بـ **Migo AI Solution**. مشروع مستقل تمامًا، منفصل عن متجر Migo، ومساحته معزولة عن أي مستودع قائم.

> الحالة: **المرحلة 1 — هيكل المشروع المعزول**. لسه مفيش أي نشر ولا أي اتصال بمزوّد حقيقي. راجع `docs/PROJECT_STATUS.md` لتفاصيل كل مرحلة.

---

## الهدف

تمكين العميل من:

- البحث عن أسماء الدومينات والتحقق من توفرها.
- استعراض الامتدادات والأسعار بالجنيه والدولار.
- تسجيل الدومين عبر مزوّد معتمد، وإدارته وتجديده ونقله.
- إدارة DNS و Nameservers ومتابعة تواريخ الانتهاء والفواتير.

## الهوية البصرية

خلفية سوداء، واجهات داكنة، **سماوي (Cyan)** كلون أساسي، تصميم Premium SaaS، متوافق مع الموبايل. العربية RTL أولًا، والإنجليزية ثانية.

## المعمارية

```
متصفح العميل
     │
     ▼
واجهة Migo Domains          (frontend/)
     │
     ▼
Migo Domains API            (workers/ + backend/)
     │
     ├── قاعدة البيانات       (database/ → Supabase PostgreSQL)
     ├── RDAP Lookup          (availability/)
     ├── مصادر التوفر         (availability/)
     ├── Registrar API        (providers/)  ← عبر Adapter موحّد
     └── بوابة الدفع          (backend/)   ← لاحقًا، بعد الموافقة
```

**قاعدة ثابتة:** الواجهة الأمامية لا تتصل أبدًا بمفاتيح المزوّد مباشرة. كل عملية حساسة تمرّ عبر الـ Backend.

## التقنيات

| الطبقة | التقنية |
|---|---|
| الواجهة | HTML / CSS / JS |
| الـ Backend | Cloudflare Workers |
| الاستضافة | Cloudflare Pages |
| قاعدة البيانات | Supabase PostgreSQL + RLS |
| المصادقة | Supabase Auth |
| الأسرار | Cloudflare Secrets (أو ما يعادلها) |

## هيكل المجلدات

| المسار | المحتوى |
|---|---|
| `frontend/` | صفحات العميل (بحث، نتائج، لوحتي، DNS، الفواتير…) |
| `workers/` | نقاط الـ API على Cloudflare Workers |
| `backend/` | منطق الخدمات والتحقق والتفويض |
| `providers/` | واجهة المزوّدين الموحّدة + Mock Provider |
| `availability/` | محرك التوفر (RDAP + مصادر احتياطية) |
| `pricing/` | محرك التسعير وهوامش الربح |
| `database/` | مخطط قاعدة البيانات والـ migrations والبذور |
| `policies/` | سياسات الخصوصية والشروط ومبادئ العمل |
| `tests/` | اختبارات التسعير والتوفر والأمان والوظائف |
| `config/` | إعدادات المشروع والقيم الافتراضية |
| `docs/` | التوثيق الكامل للمشروع |

## التشغيل محليًا

لا يحتاج أي مفاتيح إنتاج. انسخ `.env.example` إلى `.env` واملأ القيم بنفسك (لا ترفع `.env` أبدًا).

```bash
cp .env.example .env      # ثم املأ القيم محليًا فقط
```

## قواعد غير قابلة للتفاوض

1. لا تعديل ولا حذف على مشروع Migo AI Solution الحالي.
2. لا نشر بدون موافقة صريحة.
3. لا شراء أي دومين أو خدمة أو اشتراك.
4. لا تسجيل دومين حقيقي أثناء الاختبارات.
5. لا مفاتيح أو كلمات مرور في الواجهة الأمامية.
6. لا بيانات تجريبية تُقدَّم كأسعار حقيقية.
7. لا ادّعاء نجاح تكامل API قبل تنفيذ طلب حقيقي والتحقق من استجابته.
8. نتيجة RDAP غير المكتملة ليست دليلًا على توفّر الدومين.
9. لا حذف بيانات أو ملفات دون موافقة.
10. لا إنشاء حسابات أو التزامات مالية نيابة عن صاحب المشروع.
