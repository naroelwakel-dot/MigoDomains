ملكية باسمك

الدومين بيتسجّل باسم العميل الفعلي كـ Registrant، مع إمكانية تحديث بيانات الاتصال عند السماح.

أسعار شفافة

سعر التسجيل والتجديد والنقل ظاهر منفصل لكل امتداد قبل أي دفع. مفيش رسوم مفاجئة.

دعم عربي

واجهة عربي RTL أولًا، ودعم يتابع طلبك خطوة بخطوة لحد ما الدومين يشتغل.

ملكية الدومين

الدومين بتاعك، باسمك، وبياناتك تحت إيدك.

بنشرحلك بالظبط مين المسؤول عن إيه: الـ Registrant، وإدارة الـ DNS، وكود النقل (Auth Code) لما يكون مسموحًا بيه، وتنبيهات التجديد قبل الميعاد.

  • Registrant = العميل
  • لوحة تحكم لإدارة الـ DNS
  • Auth Code عند السماح بالإجراء
  • تنبيهات تجديد واضحة قبل الانتهاء

الأسئلة الشائعة

هل السعر بيشمل التجديد؟

السعر المعروض سعر التسجيل للسنة الأولى. سعر التجديد بيبان منفصل لكل امتداد قبل الشراء.

أقدر أنقل دومين عندي؟

النقل متاح بشرط أن يكون الدومين مؤهّلًا للنقل (مش مقفول، ومضى عليه الوقت المطلوب)، وسعر النقل ظاهر قبل التأكيد.

إيه البيانات اللي محتاجينها؟

بيانات الاتصال الخاصة بالـ Registrant، وبعض الامتدادات بتحتاج توثيق. بنوضّح المطلوب بالظبط قبل الدفع.
