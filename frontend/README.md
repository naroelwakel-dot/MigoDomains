# واجهة Migo Domains

واجهة ثابتة (Static) متعددة الصفحات، بدون أي أدوات بناء، وبدون أي إطار عمل. عربي RTL أولًا مع تبديل للإنجليزية LTR. متوافقة مع الاستضافة على Cloudflare Pages لاحقًا (مرحلة التصميم فقط، مفيش نشر).

## البنية

```
frontend/
  index.html            الرئيسية (البحث هو البطل)
  search.html           نتائج البحث + حالات البحث
  support.html          الدعم
  assets/
    css/tokens.css      توكنز التصميم (اتساق مع docs/DESIGN_SYSTEM.md)
    css/base.css        الأنماط والمكونات المشتركة
    js/app.js           سلوكيات مشتركة (اتجاه، قائمة، تبويبات، Toast، Modal/Drawer)
    js/search.js        منطق البحث + حالات النتيجة
  preview/              معاينة التصميم v2 (مرجع بصري، متقسمة 3 ملفات)
```

## قواعد مهمة

- **مفيش أي بيانات حقيقية ولا أي اتصال خارجي** غير خطوط Google. كل الأسعار والبيانات **تجريبية** وموسومة كذلك.
- **التحقق من التوفّر في `search.js` دالة `checkAvailability` تجريبية (MOCK)** ولازم تُستبدل بخدمة التوفّر الحقيقية (RDAP + واجهة المزوّد) قبل أي تسجيل فعلي.
- **تكلفة المزوّد والهامش وقواعد التسعير ممنوعة في واجهة العميل**، ومكانها لوحة الإدارة بس.
- مفيش أي مفاتيح أو أسرار في الواجهة، ومفيش `href` خارجي غير Google Fonts.
- أي تعديل على التوكنز لازم ينعكس في `docs/DESIGN_SYSTEM.md` والعكس.

## اللي لسه ناقص

- صفحات: تفاصيل الدومين · السلة · الدفع · دوميناتي · إدارة الدومين · التجديد · الطلبات.
- لوحة الإدارة (8 أقسام).
- ربط الباك إند (Supabase + مزوّد التسجيل) لاحقًا بعد الموافقات.
