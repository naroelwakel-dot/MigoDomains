معاينة واجهة Migo Domains قبل الاعتماد

نسخة مطوّرة من معاينة v1: تجربة هاتف حقيقية، حالات بحث كاملة، فصل أسعار التسجيل والتجديد والنقل، واجهة عميل موسّعة، ولوحة إدارة منظّمة بثمانية أقسام. المرجع البصري هو docs/DESIGN_SYSTEM.md.

معاينة تصميم فقط. كل الأسماء والأسعار والأرقام هنا تجريبية ثابتة للعرض ومش نتيجة فحص حقيقي ولا اتصال بأي مزوّد. مفيش أي عملية تسجيل دومين أو دفع أو اتصال خارجي. والملكية والحالات معروضة كنموذج تصميمي، مش وعد قانوني.

١. التسجيل باسم العميل

٢. إدارة كاملة

تعديل الدنز (DNS) وطلب Auth Code للنقل عند ما تسمح سياسة الامتداد.

٣. شفافية التجديد

تاريخ الانتهاء وسعر التجديد ظاهرين دائمًا في حسابك.

إمكانية النقل أو تعديل بيانات المالك بتخضع دائمًا لسياسات وشروط جهة التسجيل (الـ Registry / الـ Registrar) ولحالة الدومين، ومفيش وعد مطلق بخلاف ذلك.
