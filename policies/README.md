# policies/

سياسات العمل والامتثال: شروط الخدمة، سياسة الخصوصية، سياسة الاسترداد،
ومسودة سياسة Advanced DNS.

| الملف | المحتوى |
|---|---|
| `terms.md` | شروط الاستخدام |
| `privacy.md` | الخصوصية (بيانات WHOIS، الدفع، الحقوق) |
| `refund.md` | قاعدة «مفيش استرداد بعد التنفيذ» + حالات الاسترداد |
| `advanced-dns.md` | سياسة إدارة DNS (الخطة المتقدّمة **غير مسعّرة**) |
| `lib/policy.js` | الصيغة القابلة للتنفيذ: النسخ، والحالة، وفحص الموافقات |

**كل الوثائق حالتها `DRAFT`** — محتاجة مراجعة قانونية واعتماد صاحب المشروع،
والكود بيقول كده صراحةً بدل ما يدّعي إنها نافذة. الشراء بيتطلب موافقة صريحة
على (الشروط + الخصوصية + الاسترداد).

**لا سعر نهائي لـ Advanced DNS** قبل تحديد المزوّد والتكلفة والمميزات وحدود
الاستخدام والدعم.

```bash
cd policies && node --test "test/*.test.js"   # 5 اختبارات ناجحة
```

> الحالة: **الصيغة التنفيذية منفَّذة ومُختبَرة**. النصوص مسودّات بانتظار الاعتماد.
