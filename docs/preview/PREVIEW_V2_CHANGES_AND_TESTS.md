## 1) ملخص التغييرات (من v1 إلى v2)

**اتحافظ عليه زي ما هو:** نفس الهوية (أسود فحمي + رمادي معدني + Accent سماوي واحد)، نفس خطوط IBM Plex Sans Arabic / Inter / IBM Plex Mono، نفس الـ tokens (ألوان، مقاسات، مسافات، أنصاف، حركة)، ونفس الممنوعات (مفيش بنفسجي/Neon، مفيش Glow، مفيش تدرجات زخرفية، مفيش Glassmorphism، مفيش تغيير للوجو أو الاسم). التعديل كان تطوير فوق الموجود، مش إعادة من الصفر.

| القسم | اللي اتغيّر |
|---|---|
| **الرأس والتنقل** | شريط ثابت + قائمة هاتف حقيقية (زر ☰ بيفتح/يقفل بـ Escape وبيرجّع التركيز)، + زر تبديل `EN / LTR` بيقلب اتجاه الصفحة واللغة والخط. |
| **التوكنز (01)** | 16 لون مع الاسم والاستخدام والـ hex، 7 مقاسات خط حقيقية، 8 خطوات مسافات كأعمدة، 4 أنصاف. |
| **المكونات (02)** | حالات Hover/Focus/Disabled/Loading للأزرار، زر بيعرض Loading حقيقي، حقول بـ 44px، Checkbox/Radio/Switch، **17 Status pill بمعنى ثابت**، جدول بـ sticky header، Tabs شغّالة، Breadcrumb، Toasts، Skeleton، Empty state، ونافذة تأكيد + Drawer بيقفلوا بـ Escape وبالضغط بره. |
| **البحث (03) — جديد** | **خمس حالات كاملة**: جاري البحث (Spinner ثم نتيجة) · متاح · محجوز · خطأ اتصال (مع إعادة المحاولة) · اقتراحات بديلة (مع اختيار متعدد وإضافة للسلة). كلها موسومة Demo. |
| **فصل الأسعار — جديد** | سعر التسجيل / سعر التجديد / سعر النقل / مدة التسجيل في 4 بطاقات منفصلة + تنبيه إن الأسعار توضيحية. وبجوارها بطاقة "اللي مش بيظهر للعميل" (تكلفة المزوّد، الهامش، القواعد الداخلية، بيانات الحسابات، المفاتيح). |
| **واجهة العميل (04)** | Header · Hero بالبحث كبطل · شريط امتدادات بأسعار · 3 كتل مميزات بتصميم مختلف · خطوات الشراء · **قسم ملكية الدومين** (Registrant = العميل، DNS، Auth Code عند السماح، شفافية التجديد) بلا أي وعد قانوني مطلق · إدارة وتجديد · FAQ بـ `<details>` · Footer بأزرار تجريبية مش روابط وهمية. |
| **الصفحات التسعة (05) — جديد** | معاينات مصغّرة: نتائج البحث · تفاصيل الدومين · السلة · إتمام الدفع · دوميناتي · إدارة الدومين · التجديد · الطلبات · الدعم. كل واحدة بمسار وأسطر ووسم Demo. |
| **لوحة الإدارة (06)** | Sidebar بـ 8 أقسام بيتحوّل **Drawer** تحت 1100px: نظرة عامة (5 KPIs + جدول إيراد/هامش) · الدومينات · الطلبات · العملاء · التسعير (الأربع شرائح المعتمدة + تكلفة/بيع/هامش) · المزوّد/Sandbox (**غير متصل** + سجل أخطاء فاضي) · السجلات (مستخدم/عملية/وقت/عنصر/نتيجة) · الإعدادات (عملات/لغات/إشعارات/أمان). |
| **الجداول على الهاتف** | كل جدول داخل حاوية بتتسحب أفقيًا مع تلميح "اسحب الجدول أفقيًا" بيختفي عند العروض الكبيرة. |
| **RTL / LTR (07)** | بطاقة LTR كاملة + قواعد الاتجاه، والتبديل فوق بيقلب الصفحة كلها. |

**اللي مش بيظهر للعميل، مؤكَّد في التصميم:** تكلفة المزوّد والهامش وقواعد التسعير بتظهر **بس** في لوحة الإدارة (Pricing). ورسالة خطأ البحث **مفيهاش أي تفاصيل تقنية حسّاسة**، وقسم المزوّد **مش بيدّعي** إن Openprovider متصل.
