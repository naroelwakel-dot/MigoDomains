- **الأمر:** `node --test pricing/test/*.test.js` · **النتيجة:** `tests 72 · pass 72 · fail 0`.
- **النطاق:** تشغيل محلي بالكامل، بدون أي شبكة أو مفاتيح، ومفيش أي تكلفة أو سعر صرف حقيقي.
- **مخرَج العرض الحي:** `node pricing/demo.js` — والجدول اللي بيطبعه مطابق لجدول
  `docs/PRICING_POLICY.md` **بالحرف**، بما في ذلك الهامش الدقيق `4.5015`.

| اللي اتغطّى | العدد |

| الجدول الإلزامي السبعة (بالحرف، بالقيمة الدقيقة) | 7 حالات |

| تدقيق الفجوات والتداخلات (0 → 150 بخطوة 0.01) | 15,001 نقطة |
| رتابة الهامش (0.01 → 50) | 5,000 نقطة |

| سعر الصرف: طازج/قديم/ناقص/غير صحيح/غير موثوق/من المستقبل | 11 |

**ما لم يُختبر وليه:** مفيش أي اختبار على تكلفة مورّد حقيقية (محتاجة حساب
Openprovider = موافقة منفصلة)، ولا على سعر صرف حقيقي (`FX_SOURCE_URL` فاضي)،
ولا على أي قاعدة بيانات (ممنوع تنفيذ migrations).

## المزوّد الوهمي — نتيجة فعلية (8 نوفمبر 2026)

- **الأمر:** `node --test providers/test/*.test.js` · **النتيجة:** `tests 66 · pass 66 · fail 0`.
- **النطاق:** تشغيل محلي بالكامل، بدون شبكة ولا مفاتيح، ومفيش أي حساب مزوّد ولا أي عملية إنتاجية.
- **ملاحظة تشغيلية:** على Node 22، الأمر `node --test providers/test/` بالمجلد
  لوحده بيفشل (`Cannot find module`)؛ لازم صيغة الـglob.
