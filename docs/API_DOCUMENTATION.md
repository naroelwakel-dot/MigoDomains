# توثيق الـ API — Migo Domains

> **الحالة: NOT_IMPLEMENTED** — يُبنى في المراحل 4–6 على Cloudflare Workers.

## الفصل الإلزامي بين المراحل

البحث عن اسم ≠ التحقق من توفّره ≠ إصدار عرض سعر ≠ التسجيل الفعلي. كل خطوة نقطة مستقلة.

## المسارات المتوقعة (مسودة)

| المسار | الوصف | الحالة |
|---|---|---|
| `POST /search` | البحث عن اسم عبر امتدادات | مخطط |
| `POST /availability` | التحقق من توفّر دومين + وقت آخر تحقق | مخطط |
| `POST /quote` | إصدار عرض سعر (USD + EGP) | مخطط |
| `POST /order` | إنشاء طلب | مخطط |
| `GET /domains` | دومينات العميل | مخطط |
| `POST /dns` | تعديل سجلات DNS | مخطط |

**غير موجود:** أي مسار يُرجع تكاليف المورّد أو هوامش Migo.
