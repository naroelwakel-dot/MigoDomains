# معمارية DNS — Migo Domains

**الحالة: NOT_IMPLEMENTED.**

## الفصل الإلزامي

| النوع | الوصف |
|---|---|
| **Registrar DNS** | الـ nameservers/servers التي يوفرها المزوّد مع الدومين |
| **Third-party DNS Provider** | مزوّد DNS خارجي (مثل Cloudflare DNS) |

> **ممنوع** افتراض أن امتلاك Registrar API يمنح تلقائيًا كل خصائص DNS. (مثال: Cloudflare Registrar **يلزم** استخدام نطاقاته، فالتحكم في الـ NS الخارجي مستحيل.)

## Basic DNS (مجاني وفق حدود المزوّد)

- A · AAAA · CNAME · MX · TXT · CAA · NS
- Nameserver Management
- إدارة Zone
- التحقق من صحة المدخلات

> لا نَعِد العميل بميزة لا يدعمها مزوّد DNS الفعلي.

## Advanced DNS (خطة مدفوعة مستقبلية)

**ممنوع تحديد سعر نهائي** قبل تحديد: المزوّد · التكلفة · المميزات · حدود الاستخدام · الدعم الفني · SLA إن وُجد.

إعدادات الإدارة المطلوبة: سعر الاشتراك · دورة الفوترة · المميزات · حدود السجلات · حالة الاشتراك.

## واقع الأسعار (من التوثيق الرسمي)

| المزوّد | DNS أساسي | Premium DNS |
|---|---|---|
| OpenSRS | Managed DNS مجاني | — |
| Openprovider | مجاني (3 NS) | $6.49/سنة عضو، $8.99 غير عضو |
| Namecheap | FreeDNS مجاني | $4.88 جديد / $9.98 تجديد |
| Cloudflare | مجاني + DNSSEC | — (إلزامي نطاقاته) |

> دي **تكاليف** لا أسعار بيع. سعر Advanced DNS للعميل يُحدَّد لاحقًا بقواعد التسعير المعتمدة.

## تحذير تنفيذي

`setHosts` لدى Namecheap **يستبدل كل السجلات** — تُعامل كتحديث كامل للـ zone، مش إضافة سجل. نفس الحذر مع أي عملية DNS جماعية.
