## إيه اللي اتغيّر عن النسخة الأولى

النسخة الأولى كانت استكشافًا عامًا. دي نسخة مصححة تضيف 6 تعديلات جوهرية:

1. **وحدة ملكية العميل** بقت مرحلة مستقلة: كل دومين يُسجَّل ببيانات المالك الفعلي (العميل)، وليس ببيانات Migo.
2. **دورة حياة كاملة** للدومين بمنع الانتقالات غير المنطقية.
3. **فصل صريح** بين التسجيل والنقل وتغيير المالك و Internal Push وتحديث DNS.
4. **تصحيح محرك RDAP**: لا يُعتمد `rdap.org` كمصدر وحيد ولا حده حدًا عالميًا؛ وRDAP ليس مصدر تسعير، والمرجع النهائي قبل التسجيل هو Registrar Availability API.
5. **محرك طلبات ودفع** بسيناريوهات فشل إلزامية و Idempotency و Reconciliation.
6. **قاعدة بيانات أوسع** (25 كيانًا) وسياسة أمان للملكية والأسرار.

## أهم النتائج

- **العميل يقدر يكون المالك المسجّل** عند **أربعة** مزوّدين موثّقين (ببيانات مالك مختلفة لكل دومين من نفس الحساب): **OpenSRS** و**Openprovider** و**Namecheap** (نماذج موزّعين كاملة)، و**Cloudflare Registrar** (بيدعم `contacts.registrant` لكنه مش نموذج موزّع كامل) — كلهم من التوثيق الرسمي (DOCUMENTED).
- **Cloudflare Registrar: دعم بيانات المالك (Registrant) مدعوم عبر API** (بيقبل `contacts.registrant` داخل طلب التسجيل)، و**Transfer-in مدعوم بقيود عبر API** (من 30 سبتمبر 2026، مسار `POST /accounts/{account_id}/registrar/registrations/{domain_name}/transfer-in`). لكنه **غير مناسب كمنصة بيع للتسجيل الإنتاجي**: **التجديد** و**تحديث بيانات الاتصال** لسه **مش عبر API** (الداشبورد فقط)، و**Transfer-out غير موجود ضمن الـ API المُراجَع** (مش ادّعاء استحالة مطلقة)، ونقل **Premium** غير مدعوم عبر API، والـ API بيتا لامتدادات محدودة، وإلزامي استخدام نطاقات Cloudflare، ومفيش نموذج multi-tenant بعد.
- **صفر حسابات أو خدمات جديدة اتعملت، وصفر مبالغ اتدفعت.** كل الأرقام من صفحات رسمية عامة، واللي محتاج حساب اتسجّل `REQUIRES ACCOUNT ACCESS`. (حالة الشرط 11 = **TESTED_WITH_SCOPE_LIMITATION**، والدليل في `NO_PRODUCTION_OPERATIONS_LOG.md`.)
- **مفيش اتصال Cloudflare** في الـ workspace، والإنترنت مقفول من بيئة التشغيل.
- **Supabase المتصل**: منظمة `MigoAi` (`tahmqvouxphzccqulktn`) ومشروع واحد `xydgyyjpqtkmcpzbhzyf` (اسمه في نتائج الاتصال = **بريد المالك، متعمَّد عدم تكراره هنا**). **قراءة مخططه محجوبة بفحص أمان** فمش أقدر أتحقق من الجداول أو RLS أو Storage → `NOT VERIFIED`. **وجود الاتصال لا يُثبت سلامة الجداول ولا RLS.**

## المعيار النهائي

Migo Domains تبقى منصة مستقلة وآمنة، **والعميل هو المالك المسجّل الحقيقي لكل دومين منذ لحظة التسجيل**، مع حقه في إدارة دومينه ونقله وفق قواعد الامتداد.
