# عزل المستودع — Migo Domains

## المبدأ

Migo Domains مشروع **مستقل تمامًا**. مساحته الخاصة: Repository مستقل، و Cloudflare Pages مستقل، و Workers مستقلة، و Supabase Project مستقل، و Secrets مستقلة، وقاعدة بيانات منفصلة، ونطاق مستقل عن متجر Migo.

## المستودعات وقواعد الكتابة

| المستودع | الوضع | القرار |
|---|---|---|
| `MigoStore` | **ممنوع منعًا تامًا** (كتابة/تعديل/حذف/نقل) | لا يُلمس إطلاقًا |
| `MigoAi` (المتجر) | الكتابة على `main` مسموحة (Auto) | **ممنوع أي تعديل** لمشروع الدومينات |
| `MigoAIVideoAgentProfessional` | الكتابة مسموحة | **لا يُستخدم كمكان افتراضي للمشروع** |
| `MigoDomains` (جديد) | مش في قائمة السماح | **محتاج موافقة صريحة** (قرار A) |

## لماذا لا نستخدم MigoAIVideoAgentProfessional؟

السماح بالكتابة في مستودع **لا يعني** أنه المكان المعماري المناسب. مستودع الفيديو مشروع مختلف تمامًا (استوديو تخطيط فيديو عربي)، ولغته وهويته وأهدافه وديونه التقنية لا تخص منصة بيع دومينات. خلط الاثنين يخالف مبدأ العزل ويفتح باب أخطاء النشر (Pages للمستودع يتحدّث تلقائيًا).

## خطة العزل

| الطبقة | المكان المقترح | الحالة |
|---|---|---|
| الكود | Repository مستقل `MigoDomains` | REQUIRES_APPROVAL |
| الواجهة | Cloudflare Pages مستقل | REQUIRES_APPROVAL |
| الـ API | Cloudflare Workers مستقلة | REQUIRES_APPROVAL |
| قاعدة البيانات | Supabase Project مستقل | REQUIRES_APPROVAL |
| الأسرار | Secrets مستقلة (لا تشارك مع أي مشروع) | REQUIRES_APPROVAL |
| النطاق | نطاق مستقل عن متجر Migo | REQUIRES_APPROVAL |

## الوضع الحالي

بنية المشروع متجهّزة **محليًا فقط** في مجلد `migo-domains/` للمراجعة. **مفيش أي ملف اترفع على أي مستودع، ومفيش أي مستودع جديد اتعمل.**

## شرط القبول

لا يُنشأ المستودع ولا يُرفع أي ملف قبل موافقة صريحة (قرار A في `DECISIONS_REQUIRED.md`)، وبعد عرض الملفات بالكامل على صاحب المشروع.
