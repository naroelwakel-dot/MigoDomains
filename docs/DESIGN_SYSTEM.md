# نظام التصميم (الهوية البصرية وتجربة المستخدم) — Migo Domains

**إضافة إلزامية** تُطبَّق على كل واجهة Frontend للمنصة. **لا تُغيِّر نطاق المرحلة الحالية**، ومش إذن للنشر ولا لرفع أي ملف على GitHub.

> **حدود صريحة:** ممنوع إعادة تصميم متجر Migo AI Solution، وممنوع استخدام ملفاته — النظام ده خاص بمنصة Migo Domains لوحدها.

---

## 1) الهوية

- **Premium SaaS** بطابع **تقني راقٍ** (هادئ، مش صاخب).
- **خلفية أسود فحمي** (Charcoal) — مش أسود صافٍ ولا رمادي فاتح.
- **درجات رمادي معدني** (Metallic grey) للسطح والحدود والفواصل.
- **لون Accent سماوي هادئ مائل للنعناع** — لمسة واحدة، مش صارخ.
- **نصوص بيضاء ورمادية واضحة** بتفاوت كافٍ للقراءة الطويلة.

## 2) ممنوعات التصميم

- ❌ القوالب الجاهزة المنتشرة لتصميمات AI وSaaS.
- ❌ الأزرق الكهربائي · البنفسجي · الـ Neon.
- ❌ Glow المبالغ فيه.
- ❌ Glassmorphism في كل المكونات.
- ❌ التدرجات اللونية لمجرد الزخرفة.
- ❌ تكرار نفس تصميم البطاقات في كل الصفحات.

## 3) أسلوب الواجهة

- **Typography قوية وواضحة** (أوزان صريحة، مقاسات متناسقة).
- **مساحات** بيضاء وسوداء **مدروسة** (مش فراغ عشوائي ولا ازدحام).
- **Layout احترافي غير تقليدي** — الشبكة والهرمية قبل الزخرفة.
- **جداول إدارية دقيقة وسهلة القراءة** (لوحة الإدارة).
- **بطاقات بسيطة ذات حدود هادئة**.
- **أيقونات متناسقة** (عائلة واحدة، سماكة موحّدة).
- **حركات انتقال محدودة وهادفة** (تخدم الفهم، مش للاستعراض).
- **Mobile-first حقيقي** — التصميم يبدأ من الموبايل ويتوسّع.

## 4) تجربة المستخدم

- واجهة العميل **سهلة ومباشرة**.
- لوحة الإدارة **كثيفة بالمعلومات دون ازدحام** (كثافة منظّمة، مش مكومة).
- **البحث عن الدومينات هو العنصر الرئيسي في الصفحة الرئيسية**.
- **حالات الدومين والطلبات والتجديد واضحة بصريًا** (Status pills ثابتة المعنى).
- **دعم العربية RTL والإنجليزية LTR دون أخطاء** (اتجاه، أرقام، محاذاة، أيقونات).

## 6) Design Tokens

### 6.1 الألوان (مقترحة للاعتماد)

| Token | القيمة | الاستخدام |
|---|---|---|
| `--bg` | `#0A0B0D` | خلفية الصفحة (أسود فحمي) |
| `--surface-1` | `#121417` | بطاقات، لوحات |
| `--surface-2` | `#191C20` | رؤوس الجداول، عناصر مرفوعة |
| `--line` | `#24282E` | حدود هادئة وفواصل |
| `--line-strong` | `#31363D` | حدود عند التركيز/التقسيم |
| `--metal-1` | `#8B95A1` | رمادي معدني (أيقونات ثانوية) |
| `--text-1` | `#F2F5F7` | نص أساسي (أبيض) |
| `--text-2` | `#A7B0B8` | نص ثانوي |
| `--text-3` | `#6E7882` | نص خامل / تلميحات |
| `--accent` | `#3FD0C9` | Accent سماوي هادئ مائل للنعناع |
| `--accent-strong` | `#2BB3AD` | Hover / عناصر نشطة |
| `--accent-weak` | `#123230` | خلفية تظليل هادئة للـ Accent |
| `--ok` | `#34D399` | نجاح |
| `--warn` | `#F5B942` | تحذير / معلّق |
| `--danger` | `#F87171` | خطأ / فشل |
| `--info` | `#7FB2D8` | معلوماتي (رمادي أزرق هادئ، مش كهربائي) |

**قواعد:** Accent واحد فقط في الصفحة · ممنوع تدرجات زخرفية · التباين يحقق AA على الأسود.

### 6.2 الخطوط

| Token | القيمة | الاستخدام |
|---|---|---|
| `--font-ar` | `"IBM Plex Sans Arabic"` | العربية (RTL) |
| `--font-en` | `"Inter"` | الإنجليزية (LTR) |
| `--font-mono` | `"IBM Plex Mono"` | الأكواد · أرقام العمليات · الـ Tokens |

مقاسات: `display 40/32` · `h1 28` · `h2 22` · `h3 18` · `body 16` · `small 14` · `micro 12`.
أوزان: 400 / 500 / 700 / 800 (مفيش Light).

### 6.3 المسافات والشكل

| Token | القيمة |
|---|---|
| `--space-1..8` | 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 |
| `--radius-sm` | 8px |
| `--radius-md` | 12px |
| `--radius-lg` | 16px |
| `--radius-pill` | 999px |
| `--border` | 1px solid var(--line) |
| `--shadow-1` | `0 1px 2px rgba(0,0,0,.4)` (هادئ فقط) |
| `--container` | 1120px (العميل) · 1440px (الإدارة) |

### 6.4 الحركة

- مدد: `120–200ms` · منحنى: `ease-out`.
- الحركة **هادفة** فقط (ظهور/فتح/تحديد)، وممنوعة على التزيين.
- احترام `prefers-reduced-motion`.

## 7) نظام المكونات المشتركة

- **أساسية:** Button (primary · secondary · ghost · danger) · Input · Select · Checkbox/Radio · Search.
- **بيانات:** Table (كثيفة + Sticky header + فرز) · Pagination · Badge/Status pill · EmptyState · Skeleton.
- **تغليف:** Card · Section · Tabs · Modal · Drawer · Toast · Tooltip.
- **تنقّل:** Topbar · Sidebar · Breadcrumb · Command/Search.
- **قواعد:** مكوّن واحد لكل وظيفة (ممنوع نسختين) · الأزرار primary واحدة في الشاشة · Status pill بمعنى ثابت عبر المنصة.

## 8) Layout

| | واجهة العميل | لوحة الإدارة |
|---|---|---|
| العرض | 1120px متمركز | 1440px (Sidebar + محتوى) |
| الكثافة | مساحات كبيرة، محتوى أقل | كثيفة ومنظّمة |
| التنقّل | Topbar بسيط | Sidebar ثابت + Topbar |
| الأساس | البحث + مسار الشراء | الجداول + الفلاتر + التفاصيل |
| الحركة | هادئة ومحدودة | سريعة وعملية |

## 9) تصور الصفحات الرئيسية

**واجهة العميل:** الرئيسية (بحث الدومين هو البطل) · نتائج البحث والأسعار · تفاصيل الدومين · السلة/الدفع · حسابي (دوميناتي · التجديد · الطلبات) · الدعم.
**لوحة الإدارة:** نظرة عامة (KPIs) · الدومينات · الطلبات · التسعير/الهامش · العملاء · المزوّد/Sandbox · السجلات (Audit) · الإعدادات.

**قواعد الحالة:** كل حالة (Domain Status · Order · Renewal) ليها Status pill ثابتة المعنى واللون عبر كل الشاشات.

## 10) المعاينة قبل الاعتماد

تُبنى **صفحة معاينة ثابتة** (Design Tokens + المكونات الأساسية + الصفحة الرئيسية ولوحة إدارة نموذجية) للمراجعة **قبل** اعتماد التصميم الكامل. لحد ما تُراجَع وتُعتمد، **مفيش بناء واجهة كامل**.

## 11) RTL / LTR

- الاتجاه يتغيّر بالكامل (Layout · محاذاة · أيقونات الاتجاه · الأرقام).
- منطق `start/end` بدل `left/right`.
- اختبار كل شاشة في الاتجاهين **دون أخطاء** قبل اعتمادها.
