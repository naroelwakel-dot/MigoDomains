> نتيجة مراجعة التوثيق الرسمي من المرحلة صفر (8 نوفمبر 2026). الأرقام والشروط قابلة للتغيّر، وبتتأكد من المصدر الرسمي عند التنفيذ الفعلي. **لا مزوّد اتفتح له حساب ولا اتصفّل أي مبلغ.**

## المحرّكات المتاحة للتحقق من التوفر

| المصدر | الطريقة | الحدود | الملاحظات |
|---|---|---|---|
| **RDAP** | مجاني، بدون مفتاح، عبر **IANA Bootstrap** لتحديد سيرفر كل امتداد | متفاوتة لكل سيرفر | **مصدر توفر فقط، مش مصدر تسعير.** مفيش RDAP لنسبة من الـ ccTLD. **404 ≠ متاح** |
| Registrar Availability API | استعلام المزوّد المرشّح | حسب المزوّد | **المرجع النهائي قبل التسجيل** |

## الحالة الخاصة: `migoai.eu.org`

- نطاق فرعي ضمن **EU.org**، وليس تسجيلًا مستقلًا لامتداد `.org`.
- EU.org خدمة مجانية منذ 1996، **بدون API** وبدون علاقة رسمية بالاتحاد الأوروبي.
- الموافقة على الطلب قد تستغرق من أيام إلى شهور، ولا يُضمن قبولها.
- التحكم عبر **Nameservers** التي يحددها صاحب الطلب.
- **لا يمكن تسجيله عبر أي Registrar API عادي.** يجب التعامل معه كحالة يدوية منفصلة.

## الشكل المقترح للتكامل

كل مزوّد يُطبّق واجهة موحّدة (`providers/`) حتى يمكن تغييره دون إعادة كتابة المنصة:

```
checkAvailability() · getPricing() · registerDomain() · renewDomain()
transferDomain() · getDomainDetails() · updateNameservers()
getDnsRecords() · updateDnsRecords() · deleteDnsRecord() · getDomainExpiration()
```

في مرحلة الاختبار: **Mock Provider أو Sandbox فقط**. لا تسجيل حقيقي.
